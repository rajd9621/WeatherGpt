🌦️ WeatherGPT — Conversational AI for Weather Forecasting, Alerts & Climate Information

Problem Statement: SIH 2026 — SIH26068
Organization: Ministry of Earth Sciences (MoES)
Department: India Meteorological Department (IMD)
Theme: Disaster Management · Category: Software

WeatherGPT is an AI-powered conversational platform that integrates meteorological datasets, forecasting models, and disaster warning systems to provide accurate, contextual, and multilingual weather intelligence through a chat interface. It runs entirely in the browser — no server, no API key, no installation required.

Key Features

  • Real-time weather retrieval — current temperature, humidity, wind, conditions for any city worldwide
  • Natural language querying — ask in plain English or Hindi ("Will it rain tomorrow in Mumbai?")
  • NWP model integration — data from Open-Meteo API (GFS/ICON global model output), extensible to WRF
  • Extreme weather alerts — IMD-style colour-coded warnings (Red / Orange / Yellow) for heatwaves, heavy rainfall, thunderstorms, cold waves, and strong winds
  • Location-based forecasting — geocoding resolves any place name to coordinates for 16-day forecasts
  • Multilingual support — English + Hindi (Devanagari script and romanized Hinglish)
  • Climate trend analysis — historical archive data with average temperature and rainfall summaries
  • Voice-enabled interaction — Web Speech API for hands-free queries (hi-IN / en-IN), designed for rural accessibility

Use Cases

🌾 Farmers — crop-weather advisories, irrigation & spraying guidance
✈️ Aviation — visibility, ceiling, wind briefings for pilots
⚠️ Disaster managers — severe weather alerts & early warnings
📊 Researchers — climate trend & historical data analysis
🏙️ Smart cities — real-time weather monitoring
👥 General public — daily weather, rain forecasts, planning

Architecture (4 modules in one file)

  • Module 1 — WeatherService: Open-Meteo API integration (geocoding, forecast, historical archive, IMD-style alert detection engine)
  • Module 2 — NLU Engine: Natural language understanding — intent classification, location entity extraction (100+ Indian cities + Devanagari), language detection, time parsing
  • Module 3 — ResponseGen: Multilingual natural language response generation — current weather, forecasts, alerts, agricultural advisories, aviation briefings, climate summaries
  • Module 4 — App Controller: Chat UI logic, voice input (Web Speech API), message rendering, error handling with JSONP fallback for CORS

Technology

HTML/CSS/JS Open-Meteo API Web Speech API JSONP fallback Mobile-first No dependencies

How to Run

Just open this HTML file in any modern browser (Chrome/Edge recommended for voice input). If network requests are blocked by CORS (common when opening via file://), run a local server:

python -m http.server 8000 → then open http://localhost:8000/WeatherGPT.html
